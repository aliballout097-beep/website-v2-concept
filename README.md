# STACKD. — scroll-driven concept website

Cinematic one-page concept for a fictional burger brand: counter intro, exploding layers, scene timeline and a video-player style progress bar.

**Stack:** HTML, CSS, vanilla JavaScript, GSAP

**Run:** Open `index.html` in a browser and scroll.

Built by [Ali Houssein Ballout](https://asdesignlb.com/developer) (AS Design LB).
